# websites — фабрика тематических сайтов

Репозиторий для создания сайтов на разные тематики силами команды
агентов Claude Code.

- Как это работает и кто за что отвечает — см. [CLAUDE.md](CLAUDE.md).
- Подробный пайплайн — [docs/workflow.md](docs/workflow.md).
- Шаблон брифа нового сайта — [docs/brief-template.md](docs/brief-template.md).
- Чек-лист приёмки сайта — [docs/site-checklist.md](docs/site-checklist.md).
- Каждый сайт — отдельная папка в [sites/](sites/).

## Быстрый старт: новый сайт

Опиши тематику, аудиторию и цель сайта — оркестратор (главная сессия)
заполнит бриф, при необходимости уточнит детали, и проведёт сайт через
команду агентов: контент-райтер → дизайнер → разработчик → SEO-специалист.
