# Чек-лист приёмки сайта

Оркестратор проходит этот список перед тем, как отметить сайт готовым в
`sites/<slug>/README.md`.

## Контент
- [ ] Все обязательные страницы из брифа существуют
- [ ] Тон текста соответствует брифу
- [ ] Нет выдуманных фактов, которых не было в брифе/материалах пользователя

## Дизайн
- [ ] Палитра и шрифты из style-guide применены на всех страницах
- [ ] Контраст текста и фона достаточен для чтения
- [ ] Стиль визуально соответствует тематике и аудитории

## Вёрстка
- [ ] Сайт открывается без ошибок в браузере
- [ ] Все внутренние ссылки между страницами работают
- [ ] Адаптивность: мобильный, планшет, десктоп
- [ ] У изображений есть alt-текст
- [ ] В `sites/<slug>/README.md` указан стек и как запустить сайт локально

## SEO
- [ ] У каждой страницы уникальные `<title>` и `<meta description>`
- [ ] `sitemap.xml` содержит все реальные страницы
- [ ] `robots.txt` присутствует и не блокирует сайт по ошибке
- [ ] Open Graph / Twitter теги на ключевых страницах
- [ ] В `seo-report.md` явно отмечены плейсхолдеры (домен, og:image),
      которые нужно заменить перед публикацией

## Общее
- [ ] Все файлы сайта лежат внутри `sites/<slug>/`, ничего не задело
      другие сайты в репозитории
- [ ] Изменения закоммичены с понятными сообщениями
