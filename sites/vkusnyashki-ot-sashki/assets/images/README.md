# Фото блюд — как добавить

Сейчас реальных фото нет, поэтому сайт показывает тёплую плашку-заглушку
(бежевый фон + контурная иконка тарелки), как описано в дизайн-гайде
(`design/style-guide.md`, раздел 6). Технически это работает через
`onerror` у тега `<img>`: браузер пытается загрузить файл по пути ниже,
и если файла нет — показывает плашку вместо "битой картинки".

**Чтобы подставить реальное фото — просто положите файл с ТОЧНО таким же
именем в эту папку. Ничего в коде менять не нужно.**

Требования к файлу: формат `.jpg`, квадратные фото (1:1) для карточек блюд
как можно ближе к квадрату (сайт обрежет по центру, `object-fit: cover`),
широкие (4:3 или 16:9) для hero и «О нас». Кадрирование/цветокоррекция —
см. раздел 6 style-guide.md.

## Ожидаемые имена файлов

### Hero и «О нас»
- `hero-cover.jpg` — главное фото первого экрана (пельмени/вареники крупным планом)
- `hero-hands.jpg` — фото рук за лепкой (декоративное, опционально)
- `o-nas-kitchen.jpg` — домашняя кухня / процесс готовки
- `o-nas-ingredients.jpg` — свежие ингредиенты (мясо, картошка, лук)

### Пельмени
- `pelmeni-babushkiny.jpg` — Пельмени «Бабушкины» (говядина-свинина), крупные
- `pelmeni-malenkie.jpg` — Пельмени маленькие (говядина-свинина)

### Вареники
- `vareniki-luk.jpg` — с картошкой и жареным луком
- `vareniki-bekon.jpg` — с картошкой и беконом
- `vareniki-griby.jpg` — с картошкой и грибами

### Мясная продукция
- `kotlety-klassicheskie.jpg` — котлеты классические в панировке
- `kotlety-kurinye.jpg` — котлеты куриные с пассерованными овощами
- `frikadelki-kurinye-standart.jpg` — фрикадельки куриные, стандарт
- `frikadelki-kurinye-mini.jpg` — фрикадельки куриные, мини/детские
- `frikadelki-myasnye-standart.jpg` — фрикадельки мясные, стандарт
- `frikadelki-myasnye-mini.jpg` — фрикадельки мясные, мини/детские
- `otbivnye-kurinye.jpg` — отбивные куриные в сухарях

### Фаршированные
- `perzy-farshirovannye.jpg` — перцы фаршированные
- `golubtsy-nezhnye.jpg` — голубцы нежные
- `gnezda-myasnye.jpg` — гнёзда мясные

### Сырники (добавлено 2026-09-13)
- `syrniki-klassicheskie.jpg` — сырники классические, фигурные изделия из
  творога, оформленные цветочным прессом.
  Alt: «Домашние сырники классические из творога»

### Мини-галерея над меню (добавлено 2026-09-13)
- `sbor-produkcii-1.jpg`, `sbor-produkcii-2.jpg` — два коллажа-нарезки из
  разных готовых блюд (перцы, вареники, пельмени, котлеты и др.), показаны
  в разделе «Меню» перед вкладками категорий как общий «взгляд на
  ассортимент». Изначально эти два файла были присланы без подписи и по
  ошибке сначала попали в раздел «Как упаковываем» — исправлено после
  проверки в браузере.

### Как упаковываем (добавлено 2026-09-13)
Фото упаковки — не привязаны к конкретному блюду (крафт-пакет с зип-локом,
окошком и стикером «Спасибо за покупку»), заказчица будет добавлять их сама
по мере поступления материалов:
- `upakovka-1.jpg`
- `upakovka-2.jpg`
- `upakovka-3.jpg`
- `upakovka-4.jpg`

Alt-текст (общий для всех фото раздела): «Упаковка домашней еды от
«Вкусняшки от Сашки» — крафт-пакет с окошком и стикером «Спасибо за
покупку»». Если фото/видео присылают больше четырёх — можно продолжить
нумерацию и добавить ещё слоты в разметке `index.html` (`.upakovka__gallery`)
по тому же паттерну (`class="photo photo--square"`, `onerror="handleImgError(this)"`).

Полный список путей и правило подстановки заданы в `script.js`
(функция `imgPath`, id блюда → `assets/images/<id>.jpg`) и в
`index.html` (hero/«О нас» — фиксированные пути в `<img src>`).
