# SEO-отчёт — «БрусДвор» (демо-лендинг «Укладка брусчатки»)

Финальный этап учебного проекта. Ниже — что сделано и какие
плейсхолдеры нужно заменить на реальные данные перед публикацией
настоящего сайта. Содержимое `content/*.md` и вёрстка/структура
`index.html` не менялись — добавлены только метаданные в `<head>` и
файлы, перечисленные ниже.

## Что сделано

### 1. `<head>` в `index.html`

- **`<title>`**: «БрусДвор — укладка брусчатки под ключ (демо-лендинг)»
  (52 символа) — уникальный для страницы, с названием компании и явной
  пометкой «демо-лендинг» (сохраняет требование брифа не выдавать
  демо-проект за реальный).
- **`<meta name="description">`** (158 символов, в диапазоне 120–160):
  «Мощение дворов, дорожек и парковок брусчаткой под ключ: замер,
  расчёт, укладка по технологии и гарантия. Цена фиксируется в
  договоре. Демо-лендинг «БрусДвор»." — собрано из hero и «Почему мы».
- **`<link rel="canonical">`** — `https://example.com/paving-landing/`.
- **Open Graph**: `og:type`, `og:site_name`, `og:locale`, `og:title`,
  `og:description`, `og:url`, `og:image`, `og:image:alt`.
- **Twitter Card**: `twitter:card` (summary_large_image),
  `twitter:title`, `twitter:description`, `twitter:image`.
- Убран технический комментарий-заглушка «SEO-теги добавит
  seo-specialist на следующем этапе» — заменён на пояснительный
  комментарий про домен-плейсхолдер.

### 2. Структурированные данные (JSON-LD)

Добавлен блок `schema.org/LocalBusiness` в `<head>` — тип выбран как
общий `LocalBusiness` (в контенте нет данных, привязывающих компанию к
более узкому типу вроде `GeneralContractor`, поэтому не сужал тип от
себя). Поля: `name`, `description`, `url`, `image`, `telephone`,
`priceRange` (900–4500 RUB — диапазон из блока «Цены»), `address`
(`PostalAddress`), `areaServed`, `openingHoursSpecification` (пн–сб,
9:00–19:00 — из `content/kontakty.md`). Имя компании в JSON-LD прямо
помечено как «(демо, учебный проект — не действующая компания)», чтобы
структурированные данные тоже не выглядели как настоящая организация.

### 3. `sitemap.xml` и `robots.txt`

- `sites/paving-landing/sitemap.xml` — одна запись (сайт
  одностраничный): главная страница, `lastmod` = дата этого этапа
  (2026-09-12).
- `sites/paving-landing/robots.txt` — индексация разрешена (`Allow: /`
  для всех user-agent), указана ссылка на `sitemap.xml`.

### 4. `seo/keywords.md`

Ключевые слова/фразы по каждому блоку-якорю, собранные из реального
контента (`content/*.md`), без добавления тем, отсутствующих в тексте.

## Не сделано / вне рамок задачи

- Не создавался реальный файл `og-image.jpg` — фотографий на сайте нет
  по брифу (см. `README.md`), а придумывать/генерировать несуществующее
  «реальное» фото объекта было бы искажением демо-статуса проекта. Тег
  `og:image` оставлен как явный плейсхолдер-путь.
- Не добавлялись `hreflang`-теги — сайт одноязычный (ru), альтернативных
  языковых версий нет.
- `robots.txt` не блокирует ничего — индексация разрешена полностью, как
  указано в задаче (нет причин ограничивать демо-лендинг).
- Не менялись текст контента, структура секций/якорей и вёрстка —
  только `<head>` и перечисленные новые файлы.
