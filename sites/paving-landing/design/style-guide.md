# Style Guide — «БрусДвор» (лендинг «Укладка брусчатки»)

> Основа: `sites/paving-landing/brief.md`. Демо-проект, названия/телефон/фото —
> плейсхолдеры, что должно быть явно помечено в контенте и в компонентах
> (форма, футер, отзывы, портфолио) — дизайн ниже это учитывает.

## 1. Настроение и референсы

Три опорные фразы:

- **Мастеровая надёжность.** Не глянцевая корпоративная строгость и не
  «дешёвая рекламная листовка» с кричащими цветами и обилием восклицательных
  плашек — а спокойная уверенность бригады, которая давно занимается своим
  делом: чистые линии, разборчивая структура, конкретные цифры и этапы вместо
  общих обещаний.
- **Приземлённо, но не мрачно.** Материальность темы (камень, щебень, песок,
  бетон) задаёт тёплую нейтральную/земляную гамму без «строительного»
  чёрно-жёлтого шум-дизайна и без холодного корпоративного синего в духе
  IT-сайта. Много света и воздуха, но не «воздух ради воздуха» — у каждого
  блока чёткая практическая задача (объяснить, снять опасение, подвести к
  заявке).
- **Для непрофессионала, не для прораба.** Аудитория — обычные владельцы
  дома/участка, а не строители. Визуально это означает: крупные понятные
  заголовки, иконки-пиктограммы вместо строительного жаргона на картинках,
  фото «до/после» и текстуры камня как главный источник доверия (наглядность
  результата важнее абстрактной айдентики).

Референсный вайб (не для копирования, для настройки): сайты локальных
мастерских/бригад по ремонту и благоустройству, ландшафтные студии,
премиальные, но не «глянцевые» строительные подрядчики — тёплый нейтральный
фон, один уверенный акцентный цвет, крупные фотографии материала и
результата.

Специфика ниши: это услуга с высоким порогом недоверия (человек отдаёт
крупную сумму за работу, результат которой не увидит до сдачи, и боится
«просадки покрытия» и пропавших подрядчиков) — поэтому визуальный акцент на
конкретике (этапы, гарантия, договор, диапазоны цен), а не на эмоциональном
маркетинге.

## 2. Палитра

Тёплая, землистая, «каменная» гамма с одним уверенным акцентом цвета кирпича/
терракоты (ассоциация с брусчаткой) и приглушённым зелёным для «доверительных»
акцентов (гарантия, чек-марки) — без ярко-жёлто-чёрной «стройплощадочной»
палитры.

| Роль | HEX | Комментарий |
|---|---|---|
| Фон основной | `#F7F4F0` | тёплый молочно-бежевый, а не белый — «песок/штукатурка» |
| Фон альтернативный (чередование секций) | `#EDE8E1` | чуть темнее основного, для секций-«подложек» |
| Поверхность (карточки, формы) | `#FFFFFF` | чистый белый на фоне бежевого — карточки визуально «приподняты» |
| Текст основной | `#2B2E33` | тёплый почти-чёрный графит, не чистый `#000` |
| Текст вторичный / подписи | `#5B6169` | приглушённый серый для подзаголовков, подписей к фото, дисклеймеров |
| Тёмный (шапка, футер, тёмные секции) | `#2B3440` | графитово-синий, «сумерки», для nav/footer и тёмных плашек |
| Акцент основной (декоративный, иконки, бордеры, крупные слова) | `#C1622D` | тёплая терракота/кирпич — главный акцентный цвет темы |
| Акцент для кнопок/ссылок (текст и заливка на светлом фоне) | `#A8501F` | более тёмный оттенок того же акцента — используется, где нужен надёжный контраст текста |
| Акцент второй — «доверие» (гарантия, чек-иконки, галочки) | `#5B7553` | приглушённый мшисто-зелёный (трава двора, надёжность), используется дозированно |
| Разделители / бордеры | `#DCD5CB` | тонкие линии на светлом фоне, границы карточек |

### Проверка контраста (WCAG AA)

Требование AA: обычный текст ≥ 4.5:1, крупный текст (от ~24px обычного или
~18.7px полужирного) ≥ 3:1. Расчёт по формуле относительной яркости sRGB.

| Пара (текст / фон) | Контраст | Норма | Статус |
|---|---|---|---|
| `#2B2E33` (текст) / `#F7F4F0` (фон) | **12.4:1** | AA 4.5:1 | ✅ проходит даже AAA |
| `#2B2E33` (текст) / `#EDE8E1` (фон) | **11.2:1** | AA 4.5:1 | ✅ проходит AAA |
| `#5B6169` (вторичный текст) / `#F7F4F0` | **5.7:1** | AA 4.5:1 | ✅ проходит AA |
| `#FFFFFF` (текст) / `#2B3440` (тёмный фон шапки/футера) | **12.6:1** | AA 4.5:1 | ✅ проходит AAA |
| `#FFFFFF` (текст кнопки) / `#A8501F` (заливка кнопки) | **5.5:1** | AA 4.5:1 | ✅ проходит AA — безопасно для кнопок любого размера текста |
| `#FFFFFF` (текст) / `#C1622D` (декоративный акцент как заливка) | **4.2:1** | AA 4.5:1 (обычный) / 3:1 (крупный) | ⚠️ используем `#C1622D` как заливку только под крупный жирный текст (≥18px bold / ≥24px) или под иконки/бордеры без текста; для кнопок и подписей — только `#A8501F` |
| `#A8501F` (акцентный текст/ссылка) / `#F7F4F0` (фон) | **5.0:1** | AA 4.5:1 | ✅ проходит AA — можно использовать как цвет ссылок и акцентных слов в тексте |
| `#C1622D` (акцентный текст) / `#F7F4F0` (фон) | **3.8:1** | AA 4.5:1 (обычный) | ⚠️ только для крупных заголовков/цифр (≥24px), не для мелкого текста и ссылок |
| `#5B7553` (зелёный) / `#F7F4F0` (фон) | **4.7:1** | AA 4.5:1 | ✅ проходит AA, можно для мелких лейблов «Гарантия», галочек с текстом |

**Правило для разработчика:** `#C1622D` — «громкий» акцент для крупных
элементов (иконки, обводки, крупные цифры этапов, hero-заголовок на светлом
фоне и т.п.), а `#A8501F` — «рабочий» акцент для всего, что должно читаться
маленьким текстом или быть кнопкой/ссылкой. Не путать их местами.

## 3. Типографика

- **Заголовки:** Google Fonts **Oswald**, начертания 600 (Semibold) и 700
  (Bold). Условное, слегка сжатое, уверенное написание — ассоциируется с
  чёткостью и основательностью без «стройплощадочной» грубости. Поддерживает
  кириллицу.
  Web-safe фолбэк: `"Arial Narrow", Arial, sans-serif`.
- **Основной текст:** Google Fonts **PT Sans**, начертания 400 (Regular) и
  700 (Bold) для акцентов внутри текста/кнопок. Шрифт разработан для
  кириллицы (ParaType), максимально читаемый и «нейтрально-дружелюбный» —
  снижает риск, что сайт прочитается как холодный/казённый.
  Web-safe фолбэк: `Arial, Helvetica, sans-serif`.
- Итоговый CSS `font-family` (пример для гайда, не для копирования как код):
  заголовки — `'Oswald', 'Arial Narrow', Arial, sans-serif`;
  текст — `'PT Sans', Arial, Helvetica, sans-serif`.

**Базовый размер и масштаб:**

| Элемент | Desktop | Mobile | Начертание / межстрочный интервал |
|---|---|---|---|
| Базовый текст (body) | 16px (1rem) | 16px | PT Sans 400, line-height 1.6 |
| Крупный текст / лид-абзац | 19–20px | 17px | PT Sans 400, line-height 1.5 |
| H1 (hero-заголовок) | 44–48px | 30–32px | Oswald 700, line-height 1.15 |
| H2 (заголовок секции) | 32–34px | 24–26px | Oswald 600/700, line-height 1.2 |
| H3 (заголовок карточки/подраздела) | 22–24px | 19–20px | Oswald 600, line-height 1.25 |
| Подпись/мелкий текст (лейблы, disclaimer «пример») | 13–14px | 13px | PT Sans 400, line-height 1.4, цвет `#5B6169` |

Межбуквенный интервал заголовков Oswald: небольшой положительный
letter-spacing (~0.2–0.5px) на крупных заголовках — компенсирует
конденсированность шрифта и не даёт ему выглядеть «сжатым».

## 4. Layout-принципы

- **Максимальная ширина контента:** 1160px (контейнер `.container`), поля по
  бокам — минимум 16px на мобильном.
- **Сетка:** 12-колоночная на десктопе, gutter 24px. На планшете сетка
  сжимается до 8 колонок логически (карточки в 2 в ряд), на мобильном — 1
  колонка (полная ширина блока).
- **Breakpoints:**
  - Мобильный: до 767px — одна колонка, вертикальный стек, отступы секций
    48px сверху/снизу, боковые поля 16–20px.
  - Планшет: 768–1023px — карточки услуг/отзывов/цен в 2 колонки, отступы
    секций 64px, боковые поля 24–32px.
  - Десктоп: от 1024px (комфортно — от 1280px) — карточки в 3 колонки (услуги,
    отзывы), 2–4 колонки для цен, отступы секций 96px, боковые поля по краю
    контейнера.
- **Вертикальный ритм:** базовая единица отступа 8px; отступы между
  элементами внутри блока — кратны 8 (8/16/24/32), отступы между секциями —
  48/64/96 по брейкпоинтам выше.
- **Композиция главной страницы (сверху вниз):**
  1. **Nav (sticky):** логотип/название «БрусДвор» слева, якорные ссылки по
     секциям по центру/справа (Услуги, Как мы работаем, Работы, Почему мы,
     Отзывы, Цены, FAQ, Контакты), справа — телефон (демо) + кнопка-CTA
     «Оставить заявку». На мобильном — сворачивается в гамбургер-меню,
     телефон и CTA остаются видимыми в свёрнутой шапке.
  2. **Hero:** тёмный или фото-фон (крупный план текстуры уложенной
     брусчатки, приглушённый тёмный оверлей `#2B3440` при ~55–65% opacity
     для читаемости текста) + H1 с обещанием + короткий подзаголовок,
     кнопка «Оставить заявку» (primary) и вторичная ссылка «Позвонить»
     (текстовая/outline). Высота — «в один экран» на десктопе (~85vh), на
     мобильном — по контенту, без искусственного растягивания.
  3. **Услуги** — сетка карточек (4 вида работ по брифу), фон основной.
  4. **Как мы работаем** — горизонтальный/вертикальный степпер из 5 этапов
     (замер → расчёт → подготовка основания → укладка → сдача) с номерами,
     фон альтернативный `#EDE8E1`.
  5. **Примеры работ (портфолио «до/после»)** — сетка карточек-плейсхолдеров
     фото до/после, фон основной.
  6. **Почему мы** — блок преимуществ (иконки + короткий текст: гарантия,
     технология, договор, сроки), фон альтернативный.
  7. **Отзывы** — 2–3 карточки с явной пометкой «пример отзыва», фон
     основной.
  8. **Цены** — таблица/карточки по типам брусчатки с диапазонами ₽/м²,
     фон альтернативный, с пометкой «ориентировочно, точная цена после
     замера».
  9. **FAQ** — аккордеон 3–5 вопросов, фон основной.
  10. **Контакты/форма заявки** — тёмная секция (фон `#2B3440`, текст
      белый) — визуально «якорь» страницы перед футером, форма (имя,
      телефон, площадь участка) на светлой карточке поверх тёмного фона,
      рядом — телефон (демо) и явная пометка, что контакты демонстрационные.
  11. **Footer** — тёмный (`#2B3440` или чуть темнее), повтор якорных
      ссылок, копирайт, обязательная строка о том, что сайт демонстрационный
      (компания/телефон/фото — плейсхолдеры для замены перед реальной
      публикацией).

## 5. Компоненты

- **Кнопки**
  - Primary (основной CTA — «Оставить заявку»): заливка `#A8501F`, текст
    `#FFFFFF` (Oswald или PT Sans Bold, ~16–18px), радиус скругления 8px,
    паддинг 14px × 28px, при hover — заливка темнее на ~10% или переход к
    `#8F4319`, лёгкая тень при hover (не при обычном состоянии — чтобы кнопка
    не выглядела «пластиковой»).
  - Secondary/Outline (например «Позвонить», «Посмотреть цены»): без
    заливки, обводка 1.5px `#A8501F`, текст `#A8501F`, при hover — заливка
    `#A8501F` с текстом `#FFFFFF` (инверсия).
  - Ghost/текстовая кнопка внутри тёмных секций (nav, footer, hero): белый
    текст с подчёркиванием на hover, без фона.
  - Кнопки не используют яркий декоративный акцент `#C1622D` как заливку под
    мелкий/средний текст (см. раздел 2 о контрасте) — только `#A8501F`.

- **Карточки услуг** (сетка 3 в ряд десктоп / 2 планшет / 1 мобильный):
  белая поверхность `#FFFFFF` на фоне `#F7F4F0`, радиус 12px, тонкая тень
  (мягкая, короткая — `0 2px 8px` с очень низкой прозрачностью чёрного, не
  «парящая» глянцевая тень), паддинг 24–32px. Внутри: иконка-пиктограмма
  (акцент `#C1622D`, обводка/линейный стиль, без сложной детализации),
  заголовок H3, короткое описание. При hover на десктопе — лёгкий подъём
  (translateY -2/-4px) и усиление тени, без изменения цвета фона.

- **Карточки отзывов**: тот же стиль поверхности, что и у карточек услуг, но
  добавлен декоративный элемент — крупный «кавычки»-символ приглушённого
  цвета `#DCD5CB` в углу. Обязательный мелкий лейбл сверху или снизу карточки
  (например, плашка/бейдж с текстом «пример отзыва», фон `#EDE8E1`, текст
  `#5B6169`, 12–13px) — это не декоративный, а функциональный элемент,
  напрямую связанный с ограничением брифа не выдавать демо-отзывы за
  настоящие.

- **Степпер «Как мы работаем»**: 5 шагов с крупным номером этапа в круге
  (заливка `#2B3440`, номер белым, Oswald Bold) и соединительной тонкой
  линией/пунктиром между кругами (цвет `#DCD5CB`) — на мобильном линия
  становится вертикальной, шаги идут сверху вниз.

- **Карточки/таблица цен**: по одной карточке на тип брусчатки, с ценовым
  диапазоном крупно (Oswald, акцент `#A8501F` для цифр — не `#C1622D`, чтобы
  диапазон было легко прочитать), припиской «ориентировочно, ₽/м², без
  учёта основания» мелким текстом `#5B6169`. Один тип можно выделить как
  «популярный выбор» тонкой обводкой `#C1622D` 2px — единственный элемент с
  выделением на всю таблицу, чтобы не потерять фокус.

- **FAQ-аккордеон**: строки с разделителем `#DCD5CB`, заголовок вопроса —
  PT Sans Bold 16–18px + `#2B2E33`, иконка плюс/шеврон акцентом `#A8501F`,
  разворачивается плавно, ответ — обычный текст `#2B2E33` на фоне без
  дополнительной подложки (не превращать в карточки — аккордеон должен
  визуально быть легче, чем карточки услуг).

- **Форма заявки** (имя, телефон, площадь участка): расположена на белой
  карточке `#FFFFFF` с радиусом 12px внутри тёмной секции `#2B3440`, поля
  input — светлый фон `#F7F4F0`, тонкая обводка `#DCD5CB`, при фокусе —
  обводка `#A8501F` 2px. Подписи полей над полем, мелким текстом `#5B6169`.
  Кнопка отправки — Primary (см. выше), на всю ширину формы на мобильном.
  Под кнопкой — мелкий текст согласия на обработку данных + отдельная
  строка-дисклеймер, что телефон/форма демонстрационные (курсив или
  `#5B6169`, 12–13px).

- **Навигация / якорные ссылки**: горизонтальный список в шапке, текст
  `#2B3440` на светлом фоне страницы или белый на прозрачной/тёмной шапке
  поверх hero; активный/hover-пункт подчёркивается снизу линией 2px цвета
  `#A8501F` (не меняем цвет самого текста на плохо читаемый акцент). Шапка
  становится непрозрачной (белый или `#2B3440` фон с тенью) при скролле,
  чтобы текст навигации оставался читаемым независимо от фона под ней.

- **Футер**: фон `#2B3440` (или на тон темнее `#232B34`), текст `#FFFFFF`
  для заголовков колонок и `#B7BEC6`(светло-серый на тёмном, тоже проверить
  контраст — ориентировочно, использовать не темнее этого тона) для обычного
  текста/копирайта. Структура: колонка с названием и коротким описанием,
  колонка с якорными ссылками, колонка с контактами (демо-телефон,
  демо-адрес). Нижняя строка — копирайт + обязательная пометка о
  демонстрационном статусе проекта (компания, телефон, фото — примеры).

## 6. Стиль изображений

Ниша прикладная и визуально понятная — фотография должна нести основную
доказательную нагрузку (в отличие от абстрактных иллюстраций для, например,
IT-продукта).

- **Тип изображений:** реалистичная фотография (в демо — текстовые
  плейсхолдеры/заглушки с чёткой подписью, что здесь будет реальное фото).
  Иллюстрации/иконки — только линейные пиктограммы (тонкая обводка, 1.5–2px,
  скруглённые углы) для услуг, этапов и преимуществ — не заменяют фото, а
  дополняют его в местах, где фото не нужно (например, иконка «гарантия»).
- **Приоритетные сюжеты (по брифу):**
  - Фото **«до/после»** укладки — парный кадр (обычно раздельно два кадра
    рядом или slider-компонент), одинаковый ракурс/кадрирование до и после,
    чтобы сравнение читалось мгновенно. Подпись «ДО» / «ПОСЛЕ» — короткий
    бейдж на самом фото (левый верхний угол), не только в тексте под фото.
  - **Крупный план текстуры камня/брусчатки** — макросъёмка швов, фактуры,
    рисунка укладки (ёлочка, плитка и т.п.) — используется в hero-фоне, в
    карточках услуг и как фоновая текстура в тёмных секциях (с overlay,
    чтобы не мешать тексту).
  - Кадры процесса (трамбовка, подготовка основания, бригада за работой) —
    для секции «Почему мы»/«Как мы работаем», подчёркивают соблюдение
    технологии, о которой говорит бриф (подушка из щебня и песка, трамбовка).
- **Цветокоррекция/тон обработки:** естественный дневной свет, тёплый
  цветовой баланс (не холодный синеватый), умеренная (не «инстаграмная»)
  насыщенность — камень и брусчатка должны выглядеть настоящими, а не
  пересвеченными глянцевыми рендерами. Избегать: жёсткого студийного света,
  сильных теней, HDR-эффекта, обесцвеченных/чёрно-белых кадров (это отдаляет
  от «тёплого, приземлённого» тона и от ощущения реального результата).
  Для читаемости текста на фото-фоне (hero, тёмные секции) — тёмный overlay
  `#2B3440` 55–65% opacity, а не размытие фото (размытие теряет фактуру
  камня, которая здесь и есть главный аргумент).
- **Соотношения сторон (для сетки/вёрстки):**
  - Hero-фон: широкий формат, ~16:9 или шире, кадрирование по центру для
    мобильного (важная часть кадра — по центру, не по краям).
  - До/после в портфолио: 4:3 на каждый из парных кадров.
  - Крупный план текстуры (карточки услуг/декоративные вставки): 1:1 или
    4:3.
  - Кадры процесса/бригады: 4:3 или 3:2.
- **Плейсхолдеры в демо-версии:** поскольку реальных фото нет (см. брифом
  зафиксированное ограничение), каждый плейсхолдер должен: (1) занимать
  ровно то соотношение сторон, что указано выше, чтобы вёрстка не «прыгала»
  при подстановке реальных фото; (2) содержать подпись, прямо называющую
  сюжет («Фото «до/после»: мощение дорожки, плейсхолдер») — не оставлять
  пустой серый блок без объяснения, чтобы демо-характер сайта был очевиден,
  а не выглядел как забытая вёрстка.
